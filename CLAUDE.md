## Package Overview

**spatialFolds** generates cohesive training and testing folds for spatial cross-validation while preserving the spatial structure of the data. The core algorithm grows rectangular folds from focal points until reaching a target training fraction.

## Core Architecture

### Spatial Fold Generation (R/training_fold.R)

**training_fold()** implements the core spatial cross-validation algorithm:

**Algorithm:**
1. Starts with small rectangular fold centered on focal point (`center` index)
2. Grows fold incrementally by `step_x` and `step_y`
3. Continues until fold contains `training_fraction * total records`
4. Returns logical vector (TRUE = training, FALSE = testing)

**Key implementation details:**
- Memory-optimized: tracks count without materializing intermediate dataframes
- Uses while loop to grow fold until target training size reached
- Assumes xy matrix has columns "x" (longitude) and "y" (latitude)
- Creates contiguous training regions to preserve spatial structure

**Input validation:** Function assumes valid inputs; downstream visualization provides validation.

### Visualization (R/training_fold_plot.R)

**training_fold_plot()** provides diagnostic visualization:

**Features:**
- Plots training (blue) and testing (red) points

- Customizable colors and legend position
